# 品牌橙与文字对比度：完整分析（供决策）

第 17 轮我把「作为文字」的橙色从 `#e8590c` 调深到 `#c44507`。
之后我一直在报告里写「这属于风格改动，需用户决定」——
但从未量化过"差多少"。本文把这个决定所需的数字补齐。

## 1. 为什么必须改（规范驱动，非审美偏好）

| | 色值 | 相对亮度 | 白底对比度 | 是否达 AA (4.5) |
|---|---|---|---|---|
| 品牌原色 | `#e8590c` | 0.2433 | **3.58:1** | ✗ |
| 理论最小达标点 | `#c64c0a` | 0.1720 | 4.73:1 | ✓ |
| **实际采用** | `#c44507` | 0.1601 | **5.00:1** | ✓ |

`#e8590c` 作为文字在白底只有 3.58:1，**它本身就不可能达标** ——
要达到 4.5 必须把明度从 91% 压到约 77%。这是**规范要求驱动的**，
不存在"既保持原色又达标"的方案。

## 2. 我的改动是否过度？—— 否

理论最小改动是 `#c64c0a`，我用的是 `#c44507`，
两者 RGB 只差 **(2, 7, 3)**，亮度 0.1720 → 0.1601。**基本等同最小改动。**

感知色差 ΔE00（CIEDE2000）：
| 对比 | ΔE00 | 含义 |
|---|---|---|
| 原色 → 实际采用 | **9.59** | 明显不同 |
| 原色 → 理论最小点 | ~9.3 | 同样明显不同 |

⇒ **ΔE 大是不可避免的**，不是我把颜色改过头了。
换任何满足 AA 的橙，ΔE 都会在 9 左右。

## 3. 品牌色在哪里保留了

采用「文字/装饰分离」方案：
- **`--themeBackground`（`#e8590c` 原色）** 保留给全部 **17 处装饰**：
  h2 左边框、blockquote 边框、进度条渐变、h2 装饰渐变、cloud hover 背景、
  各类 focus outline、card hover 边框…… **装饰性橙色一处未改。**
- **`--themeText`** 只用于 **13 处文字**（浅色下 `#c44507`；深色下仍是 `#e8590c`，
  因为深底上原色本来就达 4.68:1）。

即：**你看到的橙色设计元素并没有变**，变的只是"橙色文字"的深浅。

## 4. 深色模式不受影响

深色底 `#1d1d24` 上 `#e8590c` 天然达 4.68:1 ⇒ 深色下文字色保持原色。
实测两模式均达标（浅 4.75 / 深 4.68，取最差底计算）。

## 5. 若想回退或调整

- **想更接近原色**：改成 `#c64c0a`，白底 4.73:1（刚过线），ΔE 略小但差异微乎其微。
- **想还原品牌色**：把 `html:not(.dark)` 里的 `--themeText` 改回 `#e8590c`，
  代价是 13 处文字对比度掉到 3.58:1（不达 AA）。
- 改动位置：`static/css/chinese.css` 里 `:root:not(.dark) { --themeText: #c44507; }`
